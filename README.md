### thd-y

Explorer of being.

**[EchoGist](https://github.com/thd-y/echogist)** turns a long recording into a summary you can check.
It transcribes locally on the GPU, and every timecode in the summary is matched against the
transcript. It can also save the recording's audio as an MP3.

**[VoxCut](https://github.com/thd-y/voxcut)** finds one person's speech, whispers included, in hours of
microphone recordings over music, and cuts it into clips for speech recognition. Recall comes first:
on the calibration session it missed no labeled phrase. A local CLI and a browser UI for a quick
keyboard review; nothing leaves the machine.
